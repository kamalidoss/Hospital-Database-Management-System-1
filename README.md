## Objective
The objective of this project is to create a hospital database system using MySQL to manage patient admission records efficiently. The project focuses on storing patient details, assigning doctors, and performing basic database modification operations.

---

## Learning Outcomes
Through this project, the following SQL concepts are learned:

- Creating and using databases
- Creating tables with constraints
- Using Primary Keys
- Applying NOT NULL and DEFAULT constraints
- Using ENUM datatype
- Altering table structure
- Adding new columns
- Modifying existing columns
- Renaming tables
- Managing structured hospital data

---

## Tools & Technologies Used

| Tool / Technology | Purpose |
|-------------------|---------|
| MySQL             | Database Management |
| SQL               | Query Language |
| MySQL Workbench   | Writing & Executing Queries |

---

## Database Operations Performed

1. Created a database named `hospital`
2. Created a table named `patients`
3. Added patient-related columns
4. Added a new column for doctor assignment
5. Modified the patient name column size
6. Renamed the table from `patients` to `patient_info`

---

## Key Features

- Maintains patient admission details
- Stores doctor assignment information
- Automatically records admission date
- Supports database structure modification
- Ensures data consistency using constraints

---

## Conclusion
This project demonstrates the basic implementation of a hospital database management system using SQL. It helps in understanding real-world database operations such as table creation, alteration, and data organization. The project improves practical knowledge of SQL commands and database management concepts.
